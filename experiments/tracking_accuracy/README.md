# Tracking Accuracy Experiments

UAV leader, TurtleBot follower (or reversed), constant velocity. Measures
tracking RMSE, mean/max/p95 tracking error, mean separation. See
`docs/experiments.md` and `docs/novelty.md` (Experiment 1 / RQ3).

Curated result summaries and their exported JSON/CSV go here. Raw
per-run exports are gitignored (`.gitignore`); copy only the runs you
want kept as reference results into this directory.
